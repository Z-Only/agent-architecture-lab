# Security policy

This is a browser-local educational simulator. It does not execute agents, call model APIs, run user code, or store API keys. Do not paste secrets into configuration files or issue reports. Saved settings remain in browser storage; exported files are under your control.

Report non-sensitive correctness bugs through GitHub issues. For a suspected vulnerability containing private details, use GitHub's private vulnerability reporting if enabled; otherwise contact the repository owner privately before publishing sensitive evidence. Do not publish credentials or a working exploit against another person's deployment.

Contributions must preserve bounded simulation, input validation, escaped rendering, external-link safety, and honest distinctions between simulation and production execution.
